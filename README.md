PROYECTO: BUSHIDO JUDO ACADEMY

Descripción:

Este proyecto consiste en la creación de un sitio web
responsivo dedicado a una academia ficticia de Judo.

El sitio fue desarrollado utilizando HTML5, CSS y
el framework Bootstrap.

El proyecto contiene tres páginas principales:

1. Página de Inicio
2. Página de Programas
3. Página de Contacto

Además, se crearon páginas individuales con información
adicional sobre cada programa de Judo.

La página principal contiene una barra de navegación,
un encabezado con imagen de fondo, información sobre
la academia y botones de llamado a la acción.

La página de Programas utiliza Cards de Bootstrap para
presentar Judo Infantil, Judo Juvenil y Adultos y
Judo Competitivo.

La página de Contacto incluye un formulario con campos
para nombre, correo electrónico y mensaje. También
utiliza validación de Bootstrap.

El sitio utiliza el sistema Grid de Bootstrap para
adaptarse a diferentes tamaños de pantalla.

También se utilizó CSS personalizado para modificar
colores, fuentes, imágenes, márgenes, bordes y otros
aspectos visuales.
